# Project Structure

This repository contains a C++ company management system. Its tracked files are organized as follows:

```text
.
├── Company System.sln                 # Visual Studio solution
├── Company System/                    # C++ project
│   ├── Company System.cpp             # Project source entry point
│   ├── clsEmployee.cpp                # Employee implementation
│   ├── *.h                            # Headers for screens, menus, employee data, tasks, dates, and utilities
│   ├── Company System.vcxproj         # Visual Studio project metadata
│   ├── Company System.vcxproj.filters # Visual Studio filter metadata
│   ├── ProjectDescription.txt         # Project description
│   └── 0                              # Tracked project file
├── README.md                          # Overview and described features
├── .gitattributes                     # Git attributes configuration
└── .gitignore                         # Git ignore configuration
```

The README describes login routing for administrator and employee roles, with administrator employee-management functions and employee profile and task functions. The filenames above reflect the tracked repository contents.
